## ☁️ &nbsp; Cloud collections

Access your collections across devices.

<ul>
  <li style="margin-top:32px;">View and manage all of your collections in one place across work and personal browser profiles.</li>
  <li style="margin-top:32px;">No more exporting, emailing, and re-importing to move data between installs.</li>
  <li style="margin-top:32px;">Ultimate protection from the risks of local data storage like browsers clearing data, profile corruption, OS cleanup tools, re-installs, low disk space, hardware failure, and lost or stolen devices.</li>
  <li style="margin-top:32px;">Control access to Session Buddy with a login.</li>
</ul>

> Note: Cloud collections will be enabled for everyone gradually as an opt-in paid feature. If you don't see it available in Session Buddy yet, you can [request access](/contact?subject=Cloud%20collections%20access&message=I%27d%20like%20to%20request%20access%20to%20cloud%20collections.).

## 🔎 &nbsp; Search improvements

Search has been improved to be much faster, easier to use, and provide more meaningful results.

- Search now matches items that include all terms instead of any term, significantly reducing result noise. This better aligns with expectations and allows results to be refined incrementally by adding terms.
- Matching has been fixed for non-Latin languages, including Chinese, Japanese, and Korean.
- Collections and history are now filtered automatically as you type and you no longer need to click the search box before typing.
- URL matching has been refined to better ignore irrelevant parts like query parameters and fragments.
- Search performance has been significantly improved.
- Fixed a bug causing infix matches to be highlighted in some cases.
- Overlapping terms are now handled correctly, word boundary detection has been made unicode-aware, and [composed/decomposed character forms](https://w3c.github.io/i18n-drafts/questions/qa-html-css-normalization.en.html) are now treated consistently.

## ✨ &nbsp; Enhancements

- You can now quickly track down tabs that are playing sound with a new "Show audible tabs only" action in the tabs menu.
- A "Cut" action has been added alongside "Copy" to make it easier to move links and tabs. Use the selection menu or keyboard shortcut <code><OSString apple="Cmd+X" windows="Ctrl+X" client:load /></code>.
- You can now create empty collections to add links to using the new `+` button in the nav sidebar.
- The source of a duplicate is now highlighted when selecting duplicates.
- The settings UI has been refreshed and organized to make it easier to find and change settings.
- A display of collection and history counts has been added under _Settings > Stats_.
- It's now possible to choose what to back up when creating a backup file: collections, history, or both.
- Clicking the browser tile now refreshes the history sidebar, no longer requiring a page reload to see the latest snapshots.
- Rendering is now 5x faster for collections with 1,000+ links.

## 🛠️ &nbsp; Fixes and Tweaks

- Fixed a bug caused by a change in Chrome that resulted in extension tabs failing to restore in some cases.
- History reliability has been tightened to prevent occasional missed or redundant snapshots.
- Fixed a bug preventing the clearing of collection titles or colors from properly synching to other Session Buddy tabs.
- "Load all collections" and "Load all history" [experiments](/experiments) have been removed.
- "Initial collection count" and "Subsequent collection count" [experiments](/experiments) now cap out at 100.
